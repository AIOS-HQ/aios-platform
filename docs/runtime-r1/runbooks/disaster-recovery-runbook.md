# Disaster Recovery Runbook

## DR Activation
1. Declare incident and activate DR command bridge.
2. Enter execution pause mode if integrity risk exists.
3. Follow scenario-specific recovery procedures.

## Scenario Modules
- Regional outage
- Service Bus outage
- Key Vault outage
- Container Apps outage
- Supabase outage
- Foundry outage
- GitHub outage

## Exit Criteria
- Services healthy
- Validation checklists passed
- Executive approval to resume normal operation
