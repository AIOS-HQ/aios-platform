# Incident Response Runbook

## Severity Levels
- P1 Critical
- P2 High
- P3 Medium
- P4 Low

## Response Workflow
1. Detect and classify incident.
2. Assign incident commander.
3. Contain impact (pause execution path if needed).
4. Diagnose via telemetry and runbooks.
5. Recover service and validate integrity.
6. Publish incident report and corrective actions.
